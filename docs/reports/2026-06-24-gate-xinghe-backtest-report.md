# Gate 星河思路策略回测报告

## 结论

两套策略均已完成实现、数据下载、1m/15m 回测和偏差检查，但当前参数不应进入 dry-run：

- A 现货版在 1m 与 15m 样本均为负收益。
- B 永续版在 15m 的空头侧盈利，但多头侧亏损更大，整体仍为负。
- 四组 lookahead-analysis 均为 `has_bias=False`。
- 四组 recursive-analysis 均未发现指标未来偏差，240 根启动窗口的最大递归差异约为 0.029%。
- 当前策略适合作为有限网格与风险控制研究基线，不适合作为实盘候选。

### A 现货版

1m 样本只产生 8 笔交易，全部亏损，样本过短且统计意义有限。

15m 样本：

- 胜率 44.0%。
- 182 笔交易。
- 组合止盈、ROI 和跟踪止盈能够稳定实现正收益退出。
- 主要亏损来自 `spot_trend_broken`：98 笔，合计约 -114.57 USDT。
- 说明当前“趋势转弱立即退出”发生过晚，平均亏损大于均值回归盈利。

### B 永续版

1m 样本：

- 24 笔交易。
- 总收益 -0.24%。
- 最大回撤 0.64%。
- 多空两侧都没有形成稳定优势。

15m 样本：

- 胜率 59.0%。
- 多头收益 -6.78%，空头收益 +2.21%。
- 总收益 -4.57%。
- 最大回撤 10.10%。
- ROI 与组合止盈合计贡献明显正收益，但趋势失效退出造成更大的尾部损失。
- AVAX 是主要拖累，单币贡献约 -4.14%。

资金费率已经由 Freqtrade 用 Gate funding-rate 与 mark 数据计入交易损益。策略还在下单确认阶段按当前历史时间点读取最近资金费率，禁止进入需要支付极端费率的方向。

| 策略窗口 | has_bias | 偏差信号 | 偏差指标 |

| A 现货 15m | False | 0 | 无 |

永续版最初把资金费率作为 informative 列合并到主 dataframe，工具将稀疏 funding 列标记为偏差。最终实现改为在 `confirm_trade_entry()` 和 `custom_exit()` 中按 `current_time` 查询不晚于当前时点的最近历史资金费率，复测后偏差消失。

- 四组检查均显示 `No lookahead bias on indicators found`。
- 1m 的 EMA180 在 240 根窗口差异约 0.002%。

## 风险判断

已实现的安全边界：

- A 只做多，最多三次递减补仓。
- B 双向但不锁仓，最多两次递减补仓。
- B 使用逐仓，杠杆最多 2 倍。
- 两套策略均有硬止损、异常波动熔断、冷却、连续止损和最大回撤保护。
- 不使用无限马丁、倍增补仓或反向开仓“解套”。

未通过的晋级条件：

- 四组样本总收益均为负。
- Profit factor 均低于 1。
- 15m 的趋势失效退出损失明显超过均值回归收益。
- 1m 永续历史仅约 6 天，不足以判断跨市场状态稳定性。

因此当前结论是：完成研究实现与技术验证，但不建议 dry-run 或实盘。
